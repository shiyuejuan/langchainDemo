5.3 Node-style hooks：不写类，一个装饰器挂钩子

函数签名像 LangGraph 节点，三种返回值

def my_hook(state, runtime) -> None（什么都不做）／ dict（状态更新，合并进 agent state，如 {"jump_to": "end"}）／ Command（更细的流程控制：跳 tools / model / end）

实跑证据（37-node-style-hooks-demo.py）

用法① 日志钩子：第 1 轮消息数 1 → 模型返回空 content 的 AIMessage（要调工具）→ 第 2 轮消息数 3 → 最终回答。工具循环被完整记录。
用法② 停止守卫：正常问题放行（模型跑 2 轮）；用户说"停止" → return {"jump_to": "end"} → 模型 0 轮，最终消息还是 HumanMessage。

类式 vs 函数式怎么选

函数式：三五行搞定一个钩子，轻量场景首选；name 默认取函数名，天然避开"重名判重"坑。
类式（继承 AgentMiddleware）：多个钩子要共享状态、需要 tools/自定义 state_schema、或要打包复用时用。
类式方法想控制跳转：在方法上加 @hook_config(can_jump_to=[...])。
