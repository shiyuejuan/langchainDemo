5.5 装饰器和类的选择

第 14 讲 · 决策指南 · 两种写法功能等价，选型看需求

① 决策树：三个问题定写法

口诀：问自己三个问题——要状态吗？多钩子共享吗？要复用吗？有一个"是"就用类；全"否"就用装饰器，一行搞定。

② 同一个"计数日志"中间件的两种写法（实跑对照）

# 方式A 装饰器 —— 没有 self，状态只能靠闭包"凑"（能跑但别扭）
def make_decorator_mw(label):
    calls = {"n": 0}                      # 闭包变量冒充状态
    @wrap_model_call
    def counting_mw(request, handler):
        calls["n"] += 1
        print(f"[{label}·装饰器] 第 {calls['n']} 次")
        return handler(request)
    return counting_mw

# 方式B 类 —— self 天然持状态，还能多钩子共享
class CountingMW(AgentMiddleware):
    def __init__(self, label):
        super().__init__()
        self.label = label
        self.calls = 0                    # self 就是状态
        self.model_starts = 0             # 供其他钩子共享
    @property
    def name(self): return f"CountingMW-{self.label}"
    def before_model(self, state, runtime):     # 共享 self
        self.model_starts += 1
    def wrap_model_call(self, request, handler):
        self.calls += 1
        print(f"[{self.label}·类] 第 {self.calls} 次（进入 {self.model_starts} 次）")
        return handler(request)
# 实跑输出（两版功能完全等价）
  [A·装饰器] 第 1 次调模型（状态靠闭包凑）
  [A·装饰器] 第 2 次调模型（状态靠闭包凑）
  [B·类] 第 1 次调模型（节点进入 1 次，self 共享）
  [B·类] 第 2 次调模型（节点进入 2 次，self 共享）
