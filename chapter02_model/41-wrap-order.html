wrap_model_call 与 wrap_tool_call 的调用顺序

第 11 讲 · 洋葱模型延伸 · middleware = [外层, 内层]，每个实例同时实现两种 wrap

① 一个 agent 循环里，两套洋葱怎么摆

MODEL 洋葱（包模型节点） TOOL 洋葱（包工具节点）
关键：两套洋葱不交叉。MODEL 四行（外层→内层→内层→外层）是一整块， TOOL 四行也是一整块；模型工位整段结束，工具工位才整段开始，结束后模型再来一轮。

② 实跑输出 → 时间轴

[外层] MODEL ▶ before [内层] MODEL ▶ before [内层] MODEL ◀ after [外层] MODEL ◀ after ← MODEL 整段结束 [外层] TOOL ▶ before [内层] TOOL ▶ before [内层] TOOL ◀ after [外层] TOOL ◀ after ← TOOL 整段结束 [外层] MODEL ▶ before ← 第 2 轮 MODEL 再来 [内层] MODEL ▶ before [内层] MODEL ◀ after [外层] MODEL ◀ after

③ 三句话记住

要点说明
各自成洋葱model 和 tool 各按 middleware 列表顺序排层：外层先进后出、内层后进先出
套在不同工位model 壳只包 模型节点，tool 壳只包 工具节点，两壳不互相嵌套
整段不交叉先 MODEL 整段 → 再 TOOL 整段 → 再 MODEL 第 2 轮（因为 LLM 决定调工具，工具结果再回 LLM）
和第 35 课的区别：35 课讲多个中间件之间怎么套娃；本课讲同一个中间件上的两种 wrap 如何分别套在模型工位和工具工位上——它们是平行的两套套娃，不是一套套娃里的内外层。
