上下文工程（Context Engineering）

第 16 讲 · 第09章 · 核心命题：模型只知道你给它看的东西

① 概念：比"提示词工程"更大的一门手艺

提示词工程上下文工程
管什么怎么措辞那一句指令每次调模型时整个输入里放什么：系统提示、消息历史、工具定义、检索资料
一句话把话说明白决定模型能看到什么
谁做写 prompt 的人整个系统：RAG 管道、记忆、中间件、agent 编排
核心命题：模型没有"事实"，只有"上下文"。回答质量 = f(上下文质量)。 上下文给错，模型不会怀疑你——它照样答，还答得很自信。

② 四大策略（配 LangChain 的落地工具）

✍️ 写 Write —— 存到上下文之外

把信息写进外部存储，需要时再取。
落地：checkpointer（45课）、记忆库、任务便签（scratchpad）。

🔍 选 Select —— 把对的拉进来

按需注入：知识进 system prompt、RAG 检索、挑工具（工具定义也是上下文！）。
落地：system_prompt、34课 FileSearch。

🗜️ 压 Compress —— 太长就缩

历史超长会挤爆窗口+烧钱+掉注意力。
落地：SummarizationMiddleware（摘要）、28课 ContextEditing（清除旧工具结果）。

🧱 隔 Isolate —— 拆开各自带

一个 agent 全知道不如多个 agent 各管一摊，互不污染。
落地：子 agent（subagent）、多 agent 编排（本章后面）。

本课 demo 演示的是 Select；28 课是 Compress；45 课 checkpointer 是 Write。 学过的中间件正好填满三个格子。

③ 对照实验：同一个问题 × 三种上下文（实跑）

问题：「智学笔的保修期是多久？」（temperature=0 可复现）

[① 无资料] system 只说"你是客服"
  回答：智学笔的保修期为一年，自购买之日起计算。     ← 靠先验"蒙"的！

[② 对资料] system 注入"整机保修 12 个月，电池 6 个月"
  回答：智学笔 X1 整机保修 12 个月，电池保修 6 个月。  ← 有据可依

[③ 错资料] system 注入"整机保修 3 个月"
  回答：智学笔 X1 整机保修 3 个月。                  ← 垃圾进垃圾出
最危险的是①：模型没资料时从预训练先验里"蒙"了一个最常见的默认值"一年"， 碰巧和真实答案（12个月）一样——看起来对，实则无据可依。哪天真实保修期改成 18 个月， 它还会答"一年"，而且你毫无察觉。没有上下文支撑的"正确答案"比错误答案更可怕。
