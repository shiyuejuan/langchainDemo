Wrap-style hooks：它不是检票员，是包装工

那 handler(request) 到底是什么？

handler 就是"洋葱的下一层"。你调用 handler(request) = 把控制权往里传一层；它返回 = 结果从最里层往回冒、再经过你这一层。所以可以形象地记：
result = handler(request) —— "放行，把请求交给下一层，拿到结果"
return handler(request.override(...)) —— "放行，但先改一改请求"
return 自己造的结果 —— "不放行，列车根本没开出（短路）"

② 注入格式要求：request.override(system_message=...) 后 return handler(改后请求) → 事前立规矩，零跳转（对照 39 课事后质检）。
