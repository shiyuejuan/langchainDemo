55c · 短期记忆 · 小白特供版（先忘掉术语，听个故事）

先想一个生活场景

你每天去同一家咖啡店。第一天你跟店员说：“我叫小明，我爱喝美式。”

第二天你又去了。你希望店员说：“小明来啦，老规矩美式？”——这就是“短期记忆”：同一个对话/同一段日子里的连续记忆。

问题是：店员每天下班，脑子就清空了。怎么让他第二天还记得你？要靠下面三样东西。

三样东西，一个都不能少

① State = 店员脑子里“今天这一班”记得的事

店员今天当班，把“小明爱美式”写在他脑子的小白板上。这就是 State（状态）—— 它只活在当下这一次对话里。下班（对话结束）就清空。

② Checkpointer = 店长的“交接本”

店长怕店员下班忘事，给每人配了个交接本：每天下班前，把今天聊过的写进本子； 明天接班的人翻开本子，照着续。这就是 Checkpointer（检查点/存档）。

没有这个本子 → 店员每天从零开始 → 你再去他问“您是？”——这就是“金鱼脑”。

③ Thread ID = 交接本上的“客户编号”

店里有几百个客户，本子得按人分开。小明标 A1，小红标 A2。 这就是 Thread ID（线程编号）——它决定“这段记忆存进哪个本子、下次从哪个本子取”。

同一个编号 → 同一本 → 记得住；不同编号 → 不同本 → 各聊各的（不串台）。

把三样凑齐，会发生什么（对照 55 课实验 0）

🌅 第 1 天：店员把“小明=A1 爱美式”写脑子 + 写进 A1 本。
🌅 第 2 天：接班店员拿 A1 本 → 翻开看到小明 → 说“老规矩美式？” ✓ 记住了
这对应 demo 里“消息 2 条 → 4 条”：第 1 天写了 2 行（你说+店员答），存进本子；第 2 天把旧 2 行取回 + 新 2 行 = 4 行。“4 行”就是“接着聊”的铁证。

拆掉其中一样，会怎样？（对照 55 课拆腿实验）

· 拆掉 Checkpointer（有脑子有编号，但没本子）
店员脑子每天清空，编号白给 → 第 2 天“您是？”→ 金鱼脑。对应实验 1、3（都是 2→2 条，说“你还没告诉我名字”）。

· 拆掉 Thread ID（有本子但不给编号）
店长拿着空白本子，不知道往哪写 → 直接摆手：“没编号我不收！”。对应实验 2 的报错 Checkpointer requires thread_id。

· 只给编号，没本子
你喊“我是 A1！”但店里没本子可记 → 还是记不住。对应实验 3。

为什么叫“短期”记忆？

55 课 demo 用的交接本是纸本（内存）——咖啡店一关门（程序退出），纸本就烧了，明天全忘。

要变“长期”，就把纸本换成电脑档案（SqliteSaver，存进文件）——店关了档案还在，下次还能调。 换的只是本子材质，规矩一模一样。

回头看那张课程公式

课程写的故事里的缺了会怎样
State店员当班脑子（小本本）根本没内容可记
Checkpointer店长交接本每天从零开始（金鱼脑）
Thread ID客户编号 A1/A2没编号→存档员拒收→报错

一句话记死

📌 想让 AI 记住“同一段对话”，需要三样：
① 当场小本本（State·记什么）
② 下班交接本（Checkpointer·怎么留住）
③ 客户编号（Thread ID·记在谁名下，不串台）
📌 三样齐 → 记得住；少一样 → 记不住或报错。
